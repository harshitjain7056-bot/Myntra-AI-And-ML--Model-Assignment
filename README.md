# Myntra AI Size Recommendation

> **AI-powered clothing size recommendation system using Machine Learning**

## 📌 Project Overview

The **Myntra AI Size Recommendation** project is a machine learning-based system designed to recommend the most suitable clothing size for an online fashion customer.

The model uses customer and purchase-related attributes such as **age, gender, height, weight, previous clothing size, brand, category, fit preference, previous purchases, and previous returns** to predict a recommended clothing size.

The project demonstrates how **Artificial Intelligence and Machine Learning can be applied in fashion e-commerce** to create a more personalized shopping experience.

---

## 🎯 Problem Statement

Choosing the correct clothing size while shopping online can be difficult because customers cannot physically try the product before purchasing.

An inaccurate size selection can lead to:

* ❌ Poor customer experience
* 🔄 Product returns and exchanges
* 💰 Additional operational costs
* 📦 Reverse-logistics challenges
* 📉 Lower customer satisfaction

This project explores an ML-based approach to provide a **data-driven size recommendation**.

---

## 💡 Solution

The system analyzes customer and product-related information and uses a **Random Forest Classifier** to predict the recommended clothing size.

### Input Features

* Age
* Gender
* Height
* Weight
* Previous Size
* Brand
* Clothing Category
* Fit Preference
* Previous Purchases
* Previous Returns

### Output

**Recommended Clothing Size**

* XS
* S
* M
* L
* XL
* XXL
